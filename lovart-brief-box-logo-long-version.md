# Lovart Brief — JoyJoin Long Version Logo (Horizontal Lockup)

## Goal
Create a horizontal "long version" logo lockup that pairs the JoyJoin box logo with the brand wordmark, for use in nav bars, headers, share cards, and marketing materials. This should be a companion to the existing v3 box logo, not a replacement.

## Concept
- **Left side:** The JoyJoin box logo (purple gift box with 气氛组柯基, 情绪树洞考拉, 慢半拍龟 peeking out)
- **Right side:** Brand wordmark — "JoyJoin" in English + "悦聚" in Chinese
- **Relationship:** The box logo acts as the icon/avatar; the text extends horizontally to the right

## Style
- Match the v3 box logo aesthetic: warm, playful, slightly dimensional low-poly feel
- Text should feel friendly, rounded, and geometric — matching the AlimamaFangYuanTiVF rounded display font feel
- "JoyJoin" — soft geometric sans-serif (Quicksand feel), letters slightly rounded, approachable
- "悦聚" — rounded, friendly Chinese characters with geometric construction, slightly playful weight
- The text and box should feel like one cohesive unit, not two separate assets pasted together

## Color
- **Box:** Vibrant Purple #8B5CF6 with the animal colors as defined in the box logo v3 brief
- **Text:** 
  - Primary version: Vibrant Purple #8B5CF6 text on transparent background
  - Inverted version: Soft White #FFFFFF text for use on purple/dark backgrounds
  - Dark version: Dark Gray #374151 text for use on light backgrounds
- **Accent:** A small Warm Coral #FF9B85 dot or flourish connecting "Joy" and "Join" or underlining the Chinese characters (optional, for energy)

## Layout variants requested

### A. Horizontal lockup (standard)
- Box logo on the left (~1:1 square proportion)
- "JoyJoin" to the right, medium weight, with "悦聚" underneath or beside
- Generous but consistent spacing between icon and text
- Transparent background PNG
- Dimensions: 2400×800px minimum (3:1 ratio)

### B. Compact horizontal (nav bar / header)
- Smaller box logo + "JoyJoin" only (no Chinese subline, or very small)
- Tightened spacing for constrained spaces
- Transparent background PNG
- Dimensions: 1600×600px minimum

### C. Stacked / centered variant
- Box logo centered on top
- "JoyJoin" below, then "悦聚" below that
- For square or vertical contexts (app splash screen, profile headers)
- Transparent background PNG
- Dimensions: 1200×1600px minimum

### D. Wide marketing banner
- Full-width treatment with box logo + wordmark centered
- Subtle Warm Beige #F5F1E8 or Soft White #FFFFFF background wash
- Generous breathing space on all sides
- Dimensions: 3840×1200px (for social covers, event banners)

## Typography feel lock
- English: Soft geometric sans-serif, rounded terminals, medium weight, slightly wide tracking
- Chinese: Rounded geometric display, thick-thin contrast minimal, friendly and modern
- Both should feel like they belong to the same visual family as the box logo

## Export
- PNG with transparency for all variants
- SVG vector version for the text portion if possible (for web scalability)
- File naming: `lovart-logo-long-{variant}-{date}-v1.{ext}`

## Anti-generic test
Could this wordmark appear in any generic lifestyle app? No — the specific purple box icon + the rounded geometric type + the "悦聚" characters should make it unmistakably JoyJoin.

## Reference
Use the same v3 box logo as the anchor asset. The text should feel like a natural extension of that world — warm, premium, playful, approachable.
