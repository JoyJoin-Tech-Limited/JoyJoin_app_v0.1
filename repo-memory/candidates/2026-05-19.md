- DATABASE_URL format: `postgres://joyjoin:<password>@postgres:5432/joyjoin`.
- CI deploy remains manual-SQL-files approach (drizzle-kit DDL skipped).
- All 122 server tests and 32 mini-program tests pass with new driver.
