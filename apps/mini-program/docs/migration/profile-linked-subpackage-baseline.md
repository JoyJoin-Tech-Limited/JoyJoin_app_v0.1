## 5. Risk Notes

1. `terms` is currently a **public auth route**. Its new subpackage path must stay public or anonymous users on the landing page will be redirected to login when tapping legal links.
2. `LandingPage.tsx` uses `<Navigator>` (declarative) rather than `Taro.navigateTo`. Navigator supports subpackage paths transparently, but the hardcoded string must still be updated.
3. `event-ticket-payment` navigates to `terms` mid-payment flow; verify the new subpackage does not require auth.
4. The combined ~124 KiB saving is modest but meaningful because the main package is already 1.91 MB (above the 1.80 MB guideline).
