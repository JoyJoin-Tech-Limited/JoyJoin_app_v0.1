## 6. Structural Gaps & Anomalies

### 6.1 Duplicate / Overlapping Topic Files
- **`docs/harness-kpi-framework.md`** and **`docs/proposals/harness-kpi-framework.md`** are **different documents** on the same topic. Risk of divergence.
- **`docs/harness-kpi-framework.md`** (root) vs **`docs/proposals/harness-design-implementation-phase-mapping.md`** — related topics spread across root and proposals.

- `docs/research/` — no `README.md`
- `docs/deliberations/` — no `README.md`

### 6.3 Stranded Files (not clearly linked from index)
- `docs/archetype-orbit-demo.html` — HTML demo; not mentioned in `README.md`
- `docs/api/industry-classification.md` — API doc for a specific domain; lightly linked
- `docs/tech-debt/connection-points-cleanup.md` — only one file in `tech-debt/`; no category index
- `docs/admin-rbac-matrix.md` — standalone; not prominently indexed
- `docs/handoffs/` — only one file; no handoff index
- `docs/qa/` — only one file; no QA index

### 6.4 Proposals with Unclear Promotion Status
Per `docs/proposals/README.md`, only `mini-program-cleanup-and-upgrade-plan.md` is marked **Approved (2026-04-19)**. The rest remain in various open states. No mechanism is documented for when proposals graduate from `proposals/` to canonical docs.

### 6.5 Broken Links (35 total)
Most broken links are caused by **incorrect relative path nesting** (e.g., `.github/.github/skills/...` or `docs/.github/skills/...`). A single regex sweep of `.github/skills/` and `docs/proposals/` would fix the majority.

### 6.6 Circular References (49 two-doc cycles)
The `.github/` AI workflow ecosystem is densely interconnected. Most cycles are **intentional** bidirectional cross-references between tightly coupled docs and do not indicate logical contradictions.

## 7. How to Update This Map

When you add, remove, or significantly change a documentation file:

1. Update the relevant section in this file (file count, canonical table, link map, or stale list).
2. If a new doc is canonical, add it to §2 and ensure `docs/README.md` links to it.
3. If a doc is deprecated, move it to §5 and note the archival action.
4. Run a link check: `find docs -name "*.md" -exec grep -l "your-doc-name" {} \;` to verify inbound references exist.
