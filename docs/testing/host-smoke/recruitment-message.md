# 首次主持体验研究招募文案

> 文案日期：2026-10-29。主执行日为 2026-10-30，候补执行日为 2026-10-31；两天内完成。若改期，发送前把两处都改成实际绝对日期，不使用「今天」「明天」「本周末」。

## 可直接粘贴的招募消息

我们正在招募 5 名志愿者，参加一项线下多人活动的主持体验研究。你不需要主持经验，也不需要提前学习任何材料；现场只需按自己的理解完成一场约 15 分钟的活动，前后合计约 40 分钟。

研究时间：2026年10月30日 09:30–18:30，每人一个独立时段；如该日时段已满，可安排 2026年10月31日同时段。地点在确认报名后单独告知。活动使用现场统一提供的同型号手机，并需要你登录自己的微信。研究会录制操作屏幕和现场过程，仅用于本次体验分析；报名即表示你知悉并同意这项记录。

本批只接受彼此不认识的报名者，每人只能参加一次，不能旁观其他人的场次，也不能在参加前后与其他候选者交流场次内容。请先回答下面的筛选问题；符合全部条件后，我们会分配具体时段。

## 筛选问题与录用规则

请让候选人逐题回答，保留原始回答。括号内是录用标准，不随招募消息透露答案。

1. 你是否以任何方式使用过 JoyJoin，包括正式版、体验版、开发版、内测、报名活动或进入过破冰 session？（必须回答完全没有。）
2. 你是否看过 JoyJoin 破冰主持的活动说明、设计文档、测试协议、操作演示或他人测试过程？（必须全部没有。）
3. 你或你的直系亲属是否曾是 JoyJoin 内部员工、外包成员，或参与过该功能的设计、开发、内容制作、测试？（必须全部没有。）
4. 你以前是否参加过本次主持体验研究，或已经跑过一场？（必须没有；本研究一人一场，参加过就不再符合「首次」。）
5. 你是否认识本批其他报名者，或计划与他们讨论本次活动？（必须互不认识，并同意不旁观、不交流；发现同组相识则只保留一人或另批招募。）
6. 你能否在指定时段独自到场，使用自己的微信登录统一设备，并接受全程录屏和记录？（必须全部同意。）
7. 到场时你是否愿意再次确认：没有提前查看操作攻略，没有参加过一次补跑，也不会把现场内容告诉后续候选者？（必须同意。）

任一答案不符合就不安排。到场发现曾使用产品、看过文档或参加过一次，应立即排除并换人；该人不算 INVALID，也不占 5 人样本。不得以「只看过一点」「只用过旧版」放行。

## 到场后唯一 briefing script

开始录屏并确认 T0 记录方式后，facilitator 只能照读协议 §2.1 原文：

> 「今晚你是这桌的主持人，6 个人。活动大概 15 分钟，我会在旁边记录你的操作。过程中我不回答问题，也不提示。开始吧。」

照读前后都不得补充按钮位置、提示入口、功能名称或操作建议。
