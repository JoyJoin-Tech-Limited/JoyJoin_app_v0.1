# [v0.2] Wire reverse-geocoding into mini-program location filter

**Status:** Backlog | **Priority:** Medium | **Labels:** v0.2, mini-program, location

---

## Goal

Replace the hardcoded Shenzhen-only `shenzhenClusters` in `LocationFilterDrawer` with dynamic map-based district resolution, enabling multi-city district selection without code changes.

## Current State

- **Mini-program:** `LocationFilterDrawer` renders hardcoded `shenzhenClusters` from `packages/shared/src/districts.ts` (2 clusters, 9 districts)
- **Server:** `POST /api/geo/reverse-geocode` calls Tencent Maps REST API for reverse geocoding (`apps/server/src/routes/domains/geo.ts`); migrated from AMap on 2026-06-17
- **Server:** `GET /api/config/map` returns Tencent Maps API key (admin-gated)
- **Admin portal:** `MapPicker.tsx` with Tencent Maps UI works for venue creation (`AmapPicker.tsx` deleted)
- **Mapping infra:** `districtNameToClusterId` + `externalDistrictToClusterId` in `districts.ts` bridges map output → JoyJoin internal cluster IDs

## Required Work

### 1. Server: Multi-city districts endpoint
Create `GET /api/cities/districts?city=深圳` that returns district clusters for a given city. Initially powered by hardcoded data (extracted from `districts.ts` into a city-keyed map).

### 2. Mini-program: Dynamic district loader
- Before opening `LocationFilterDrawer`, fetch `GET /api/cities/districts?city={discover.city}`
- Pass dynamic clusters as props instead of importing `shenzhenClusters` directly
- Add loading skeleton while districts fetch

### 3. GPS → City resolution
- On Discover mount, call `wx.getLocation()` → `POST /api/geo/reverse-geocode` to detect user's city
- If detected city has no JoyJoin pools, show City Unlock CTA instead
- Cache resolved city in storage to avoid repeated permission prompts

### 4. Clean up hardcoded data
- Keep `districts.ts` as the single source of canonical district data
- Convert it to a `city → clusters` map format to support future cities

## Out of Scope
- City unlock flow (already done in v0.1)
- Map rendering inside mini-program (text-based district tiles only)
- Dynamic venue geocoding on mini-program (admin portal handles venue creation)

## Dependencies
- `TENCENT_MAP_KEY` must be set in production .env
- First city beyond Shenzhen must exist before this is useful in practice
