# Lovart Design Briefs: Icebreaker Phase Art Bands (2026-07-17)

> Five contained art bands for the PhaseHeroCard top band (`artUrl` slot),
> one per phase: micro_challenge, lie_detective, auction, personality_dice,
> speed_friending. Generated as ONE coherent family — same style lock, same
> canvas, same composition grammar; only accent + cast + motif change.
>
> Usage: paste each brief into Lovart ChatCanvas. Generate the family in ONE
> conversation so style stays locked across the five bands ("same series as
> the previous image" for bands 2–5).

---

## 0. Why new art (context for the designer)

- The existing `assets/lovart/icebreaker/backgrounds/bg-*.jpg` are **portrait
  full-bleed backgrounds** (750×1000) built for white text over saturated art.
- The new PhaseHeroCard uses a **contained top band** (full card width, ≤40%
  height, `mode='widthFix'`, **no text over art**), sitting on a quiet warm
  tint. Portrait full-bleed crops badly and fights the premium frame.
- New family: **landscape banner 1500×560 px** (2x for 750×280 display),
  character-forward, atmospheric tint-matched wash, generous negative space.

## 1. Shared brand block (paste at the top of every brief)

```
Brand system (JoyJoin):
- Primary anchor: Vibrant Purple #8B5CF6 (use sparingly, accents only)
- Page warmth: Warm Beige #F5F1E8, Soft White #FFFFFF
- Never: neon colors, dark moody backgrounds, sharp cold textures, 3D render,
  photorealism, text or letters anywhere in the image

Style lock (插画风统一 — MANDATORY, same as previous JoyJoin series):
- 2D digital illustration, low-poly / geometric faceted aesthetic
- Painterly, soft brushed feel within each polygonal facet (not flat vector)
- Minimal or no outlines — facet edges define form
- Soft gradients within individual facets, not global gradients
- Atmospheric textured background with subtle grain/noise
- Geometric polygonal animal characters, large expressive glossy eyes,
  simplified features, warm expressions
Canvas: 1500×560 px landscape banner. Composition: characters in the left or
right third, breathing room elsewhere, no vignette border, no frame, no text.
Background wash: very light tint of the phase accent (8–12% saturation feel),
must read as a gentle colored mist, not a solid color block.
```

## 7. Export & handoff

| Step | Action |
|------|--------|
| 1. Generate | Run the 5 briefs in ONE Lovart conversation (style continuity). Ask for 2 variations of band 1 to calibrate, then lock the series. |
| 2. Review | Checklist: no text in image · no dark/moody background · tint reads as mist on cream · characters glossy-eyed faceted · all 5 feel like one series. |
| 3. Convert | PNG → WebP q≈80, 1500×560 (keep 2x). Reuse an existing optimizer pattern (`apps/mini-program/scripts/optimize-ceremony-batch-c.mjs`). |
| 4. Name | `band-micro-challenge.webp`, `band-lie-detective.webp`, `band-auction.webp`, `band-personality-dice.webp`, `band-speed-friending.webp` |
| 5. Place | `apps/mini-program/src/assets/lovart/icebreaker/bands/` (source for CDN; do NOT bundle in the package — CDN-only). |
| 6. Register | Add all 5 to `apps/mini-program/scripts/cdn-asset-manifest.json` `assets` list with `cdnPath: assets/lovart/icebreaker/bands/<name>.webp`. |
| 7. Upload | `npm run upload:cdn-assets` (or the Upload CDN Assets workflow). |
| 8. Wire | Set `artUrl={cdnAsset('/assets/lovart/icebreaker/bands/band-<phase>.webp')}` on the five hero views' `PhaseHeroCard` call. |

## 8. Acceptance checklist (per band)

- [ ] 1500×560, WebP, ≤120KB each
- [ ] Zero text/letters in the image
- [ ] Background is a light tint mist (not saturated, not dark)
- [ ] Phase accent color reads clearly but covers <20% of the canvas
- [ ] Characters match the archetype personality table
- [ ] Family consistency: same facet style, same grain, same eye treatment
- [ ] Renders correctly in the PhaseHeroCard art band (`widthFix`, no crop)
