# 阿团第二、三幕背景设计与交互地图

## 目标

沿用阿团第一幕的分层方式：场景背景负责提供可观察物件，阿团角色、对白、热点状态和小游戏反馈由独立图层渲染。背景本身不烘焙文字、按钮、发光圈或角色。

## 品牌参数

- 主锚点：Vibrant Purple `#8B5CF6`
- 暖色高光：Warm Coral `#FF9B85`
- 平静阴影：Sky Blue `#A8C5DD`
- 植被：Fresh Green `#9ACD32`
- 基底：Warm Beige `#F5F1E8`
- 高光：Soft White `#FFFFFF`
- 结构灰：Medium Gray `#9CA3AF`、Dark Gray `#374151`
- 风格：2D 低多边形几何切面、纸感软笔触、少描边、克制渐变、暖而不幼稚。

## 生成提示词摘要

两张图均以 `flash-atuan-park-clean-v3.jpg` 作为风格参考，要求严格 9:16、中央 60% 安全区、顶部/底部 UI 留白、无角色、无文字、无 UI、无高亮效果。第二幕强调“调整距离前的犹豫”，第三幕强调“把邀请说清，但不替对方回答”。

## 下游交付约束

- 小程序用 `Image mode='aspectFill'`；热点坐标必须在至少两种模拟器比例下验证。
- 高亮使用独立 Taro `View`，状态为未发现、聚焦、已发现；不能只靠颜色表达。
- 可移动椅子、名牌和卡片属于小游戏图层，不从背景图中裁切后拖动。
- 阿团继续复用已批准的透明角色素材，不生成新的角色版本。
