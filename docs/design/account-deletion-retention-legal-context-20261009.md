## 2. 对 Option B 的中性影响

以下仅说明"已核验条文"与 Option B（保留 `payments` 等行并去标识化）之间的事实关系，不构成建议。

- **候选最短法定期限。** 若律师认定 JoyJoin 属于适用《电子商务法》第三十一条或《网络交易监督管理办法》第三十一条的主体，则"支付记录/交易信息"类数据自交易完成之日起不少于三年。三年是已核验条文中的最短年限表述；若会计/税务口径成立，候选期限为10年（涉税资料）直至附表档次（10年/30年，具体行项未核验）。
- **PIPL 的例外结构。** 第四十七条第二款允许在"法定保存期限未届满"期间继续存储，但要求停止存储与必要安全保护之外的处理；第五十一条第（三）项与第七十三条第（三）项使"去标识化"成为可用的安全措施之一。Option B 的关键事实问题（判断权在律师）：`payments.user_id` 置 NULL 后，行内其余字段（如任何仍可关联到用户的标识或 `event_registration_payload` 的偏好数据）是否使"去标识化"成立。
- **退款能力与删除时点的关系。** 微信支付退款窗口为支付成功后365天；超过该窗口的订单不能通过该接口原路退款。删除流程若在窗口期内移除 `wechatOrderId` 等查找键，将影响"场次未成行"自动退款的执行；保留本库行则保留该能力（事实陈述，不做取舍）。
- **商户侧账单不足以替代本库留存。** 腾讯侧账单接口仅覆盖近三个月，且 download_url 有效期5分钟；更早交易的核对依赖 JoyJoin 自行保存的数据。此为"本库保留"的事实性支持论点之一。
- **用户告知面的条文组合。** PIPL 第十七条（处理前告知，含保存期限）、第四十七条第二款（法定保留例外的处理限制）、电子商务法第二十四条（注销时"依照法律、行政法规规定保存的，依照其规定"）共同构成"注销 + 依法保留"告知面的条文基础；15个工作日删除承诺与保留事实如何并存，属文案与合规判断，须律师审核。
- **未决定性。** 是否构成"电子商务平台经营者"、`payments` 等行是否构成"交易信息/支付记录/会计资料或涉税资料"，均为法律定性问题；不同定性对应不同期限下限与不同义务主体。

## 4. 建议律师回答的具体问题（对 memo §4 Q1–Q10 的细化）

- **Q1（定性，对应 memo Q1）**：JoyJoin 的活动报名与票务是否构成《电子商务法》第二条的"电子商务"？我方是否落入第九条第二款"电子商务平台经营者"，从而适用第三十一条保存义务？若不是，是否有其他主体定性使该条或《网络交易监督管理办法》第三十一条间接适用？
