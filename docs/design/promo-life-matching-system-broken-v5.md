## 幕 1 · 冷开场(0-4s)——记忆点:倒着走的城市

| 时间 | 节拍 |
|---|---|
| 0-0.5s | 黑屏。**地铁报站声倒放**起:「叮咚——」反向拉长 |
| 0.5-2.5s | 门推开,暖光**瀑布**涌出(第一次:猛烈、陌生),四人转头微笑。画面右下角桌沿,**一杯没喝过的外带咖啡**(0.5s 内嵌特写,第一遍无人注意) |
| 2.5-4s | 定格 → **整城倒放**:人群倒退着走路、咖啡店蒸汽被吸回、外卖员倒着骑车。字幕「24小时前」 |

- **功能:** 钩子 + 盲盒结构(先见结果)+ 藏谜面(咖啡杯)
- **声音:** 倒带音落点 = 地铁报站倒放 + 人群声倒放
- **陀螺:** 观众此刻不知道,那杯咖啡就是结尾的门票

## 幕 2 · 错过警告(4-16s)——记忆点:推路人雕像

| 时间 | 节拍 |
|---|---|
| 4-8s | 日常建立:启哲手持咖啡,步伐轻快,南山科技园街道,人流正常(微晃手持) |
| 8-14s | **半程一镜(10-12s 降级版)**:贴地飞行长镜,从启哲肩膀起——路人依次冻结,**启哲试探性推一个冻结路人,路人像雕像倾斜 30°,他赶紧扶回去**;第二个路人冻结时弹出 UI「**下辈子见 已错过**」;冻结声=人群声磁带卡住「嗡—」一次比一次长 |
| 14-16s | 启哲被 UI 包围,「今日社交效率 2%」卡弹出。角落小字**改视觉梗**:启哲头顶冒出一格漫画小剧场——沙滩度假的自己,一行小字「**至少那边没人冻住**」 |

- **功能:** 异常升级,恐慌渐起
- **变化(刀三+改二):** B 一镜砍成 12s 半程;「-98%」数字梗删除,换成脑内漫画视觉梗

## 幕 3 · 社交灾难(16-28s)——记忆点:「已过:1个世纪」

| 时间 | 节拍 |
|---|---|
| 16-20s | 饭局立三人设:车钥匙「装逼值:99%」/ 保险单「业绩压力:MAX」/ NFT猴「韭菜指数:100%」;启哲筷子悬空「社交进度:加载中…」 |
| 20-22s | NFT 男凑近嘴型激动,UI「检测到危险信号:话术重复率90%」,小字时间戳「**3分钟前:他还在聊Web3**」;启哲后仰 |
| 22-24s | 炫富男忘词「记忆碎片:找不到」;保险女「假装在回重要信息」;**死寂中,启哲手机突然震动(观众会低头看自己手机,第四堵墙梗)** |
| 24-26s | UI 角落「**已过:1个世纪**」(数字梗保留,全片唯一) |
| 26-28s | 服务员推门扫视,对讲机:「3号包间气氛有点冷,加热器多拿两个」(**一字不改**);「-5℃(物理温度25℃)」;退出前小字「**备注:本桌建议下次预订4人以下**」 |

- **功能:** 喜剧高峰 · 社恐共鸣(全片资产,骨架零改动)
- **声音:** 死寂对比 + 远处别桌笑声 + 手机震动

## 幕 4 · AI 递盒(28-43s)——记忆点:微缩深圳 + 遛人步数

| 时间 | 节拍 |
|---|---|
| 28-31s | 启哲推门而出,世界冻结。AI 界面逐字:「检测到严重社交事故」「是否修复人生匹配系统?」——界面角落,**悦仔的像素剪影眨了下眼**(系统人格=悦仔,产品里悦仔就是引导者);启哲疯狂点头 |
| 31-36s | **签名段 · 上帝视角微缩(0-5s 移轴)**:高空俯瞰,福田 CBD 变移轴微缩玩具城,无数暖红光线如血管织成网,一条红线从天空垂落 |
| 36-43s | **签名段 · 贴地全速(5-15s)**:红线缠上手腕但**只带路不拖人,启哲自己跑**;红线 UI「**别磨蹭,我6点下班**」;穿过遛狗大爷,狗与启哲对视「**今日遛人步数:5000**」;街角盲盒机旁,**悦仔从盲盒机后探出半个脑袋**——彭布罗克威尔士柯基 clay 手办质感,紫 hoodie、黑框圆墨镜挂领口,举着一张**紫色盲盒邀请卡**;启哲被带过时,悦仔**眨眨眼**;UI 微标「街头盲盒进行时」(3s,无对白);「**今日盲盒:6人饭局 · 19:00**」小字「打开方式:**推门**」;红线消失前「**本次旅程由红线为您导航**」 |

- **功能:** 转折 · 系统降格为揭晓者(启哲自己跑=主动权的第一小步)+ 街头盲盒(第二种开盒方式)演示
- **悦仔定位:** 片中悦仔是**品牌吉祥物在城市里做引导**(不是街头盲盒运营 NPC——运营 NPC 目录 阿浪/栗子/默默/拾柒/阿团 留在产品侧,不出镜);递的是**盲盒邀请卡**不是任务卡,弱化运营派单语义,强化开盒邀请语义
- **变化(刀二):** 微缩只给上帝视角,贴地全速段切正常视角,速度感不丢
- **声音:** 微缩段俯视风声 → 贴地段急促脚步 + 一闪而过夜市/街头艺人音乐(城市生命力)

## 幕 5 · 正确相遇(43-52s)——记忆点:系统自觉闭嘴

| 时间 | 节拍 |
|---|---|
| 43-46s | 餐厅门口,手放门把,**停一秒**——把咖啡杯放在门边,杯沿轻响(告别独行,无声仪式)。**自己推门** |
| 46-50s | 光瀑门**第二次:更暖更稳**(质量变化=情绪进化)。林薇倒茶,启哲张嘴无言,阿杰促狭——「**不,是正确的人。**」(此句由**悦仔的语气**读出,系统人格收尾);「同频指数 99%」卡弹出——**又自己缩回去**(系统自觉闭嘴,幕 5 唯一保留的梗);窗外,幕 2 所有「已错过」卡片化作光点飘进来,落在杯沿(视觉 callback) |
| 50-52s | 四人碰杯,定格。空握的咖啡杯被阿杰倒上茶——**杯子从独行到共饮,零台词完成人物弧线** |

- **功能:** 启哲的选择 + 盲盒揭晓
- **变化(刀四):** 梗清零,只留「系统闭嘴」;笑点预算全部前移
- **声音:** 幕 1 的倒放音此刻**正放收尾**——地铁报站声正常响起,世界恢复正常(同一声音,倒放=混乱,正放=温暖)
