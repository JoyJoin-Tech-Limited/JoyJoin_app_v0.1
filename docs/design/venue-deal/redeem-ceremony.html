同桌凭证｜「到店出示」的仪式感设计

版本 v2.3 简洁高级稿 日期 2026-11-13 范围 仅出示页，其余触点沿用 v2 状态 未实现 · 主体 v2 已获设计批准

1方向：把「出示优惠」改成「亮出这桌的凭证」

用户付完 ¥88 之后，唯一一次当着别人面打开悦聚的时刻就是到店出示。这一页如果只是一张优惠券，它就是工具；如果它是这一桌的凭证，它就是身份。仪式感由五个真实事实承担：店名、活动时间、同桌人数、专属暗号、本场印章 —— 全部是系统里已有的数据，不靠形容词堆出来。

措辞约束：品牌已废止「会员 / VIP」类叫法，因此这里不出现会员卡、黑卡、贵宾等词。仪式感的载体是「同桌凭证」与「本场专属印章」，称谓是「这桌的客人」而非「会员」。同时遵守微信审核语汇：不出现匹配、社交、灵魂、撮合、AI。
「接头暗号」已改为「到店暗号」（评审意见）：接头 + 印章 + 编号的组合会把仪式感推向秘密接头或票证交易，与轻松真诚的调性不符；印章与凭证保留，措辞交 copy owner 终审。
  • 暗号仍是第一焦点（沿用评审 P1-4）：仪式层只加在凭证外框，店员两秒内还是先读到暗号。
  • v2.3 再做减法（产品方向：精美、简洁、大气、高级）：删掉凭证内层描边、虚线牌匾盒、印章旋转与英文行、顶部 eyebrow 与副标题。纸面单色，暗号区只留上下两根细线；印章单环端正。全页只剩四个信息层：店名与时间 → 暗号 → 权益 → 一条规则。
  • 深色底只用于这一页：它是全产品唯一的「舞台页」，与日常暖白界面形成场合感反差，不扩散到其它页面。
  • 印章只记录真实动作：初始 = 「本场专属」；复制暗号后 = 「暗号已复制」。它不代表门店已出示、已使用或已核销 —— 本期没有核销端，就不伪造履约状态。复制时间戳在 v2.3 中省略，状态语义不变。

3动效与触觉：只演一次，240ms 内结束

仪式感应发生在打开的瞬间，之后页面必须绝对安静 —— 用户正把手机递给店员。无循环动画、无粒子、无声音。

复制失败按钮不变绿、印章不翻转，提示「复制失败，请直接念给店员：{暗号}」失败提示只在失败时出现，不与成功态同屏
