1设计原则：两种权益，一条规则

优惠是转化工具，不是阅读理解题。用户只需要知道「我得到什么、在哪用、怎么用」，门店只需要知道「给什么、怎么给」。因此只保留两种一句话能讲完的权益，规则全平台统一为一句话：仅限本场活动，到店出示即可。

保留（用户能感知的全部）

  • 统一折扣：悦聚同桌 8 折，无门槛，全单通用
  • 定制套餐：悦聚专属 6 人餐 ¥598，含什么一句话
  • 兑换方式：出示本页 或 报一句中文暗号
  • 唯一规则：仅限本场活动当天、本桌使用
  • 费用边界一句话：订座费不含餐费，餐费到店另结

删除（v1 有，v2 全部砍掉）

  • 满 ¥200 可用（min_spend）
  • 最高优惠 ¥N（max_discount）
  • 每桌限用一次 / 每人限一份（per_person_limit）
  • 有效期起止、排除日期（valid_from/until、excluded_dates）
  • 「使用规则」折叠层（terms）
  • fixed 立减第三种数值形态（并入折扣）
  • qr_code 扫码核销（无码图字段、无核销端）
为什么敢删：权益有效期天然就是「这一场活动」，不需要独立日期系统；没有满减门槛，「出示即可用」才成立；没有每桌限次，就不需要同桌核销状态机。门店侧的执行动作也只剩一个：看到悦聚页面 → 打折 / 出套餐。

2触点 1 · 报名页「费用包含」第 5 格

场地在排桌后才分配，报名时只能承诺、不能展示具体门店优惠。第 5 格只说价值名称，teaser 只说兑现方式与费用边界，不复述同一句卖点。

3触点 2 · 场地分配后的「本场专属」卡

挂在 pool-group-detail 地点信息卡正下方，同卡复用到 event-detail 与集结房间。票券形态保留（左值右文 + 打孔虚线），装饰减到最少。一场只给一个权益：折扣与套餐二选一，由门店决定，不堆叠、不并列。

4到店出示页：凭证第一，折扣第二

v1 的 152rpx 折扣比暗号更醒目，店员第一眼读到的是折扣而不是凭证 —— v2 反转主次：暗号 / 出示动作是主角，折扣退为下方的确认信息。点卡任意位置进入本页（整卡一个点击目标，pressed 态整卡下沉，不再有 chip 与整卡两个竞争入口）。

出示页已升级为「同桌凭证」仪式版：见同目录 redeem-ceremony.html（深紫舞台 + 米色凭证 + 本场印章 + 桌号序列号，打开动效 ≤240ms）。本节 F1/F2 保留为该页的信息层级与可读性基准，仪式版不得牺牲暗号的第一焦点地位。

7评审打回项的处置

评审条件v2 处置
P0-1 确定性权益必须有确定托底保留为硬门槛：第 5 格 / teaser / B0 仅在该池保底权益覆盖最终场地与活动当天时渲染，否则全部不出现。hasVenueDealPotential 不足以托底，已明确不采用。
P0-2 不得以「出示即可使用」掩盖条件门槛类条件已整体删除，「无门槛 · 全单通用 · 到店出示」成为事实而非话术；价格下新增「订座费不含餐费，餐费到店另结」。
P0-3 不展示机制无法兑现的规则qr_code 与「每桌限用一次」从设计中移除，因此不再需要码图字段、核销端、同桌已使用状态。仅剩 show_page / code 两种已可实现的兑换方式。
P1-4 出示页主次与点击反馈暗号升为第一焦点（88rpx），折扣退为确认条；整卡单一点击目标 + pressed 态；复制按钮 ≥88rpx，补 copied / failed 反馈。
P1-5 真实页面约束与关键状态本稿补长内容、读取失败、已复制三态与加载骨架约定。复审结论：真实 Step 0（普通屏 + 短屏）转为实现期 ship 前置验收，不再要求静态稿伪造通过；验收点为订座 CTA 不被挤出、第 5 格 / teaser / 费用边界不得沿用现有 collapse 逻辑无提示消失（现有 PoolRegistrationInclusions 为固定单排四格且短屏整段隐藏）。
P1-6 视觉不合格项B0 孤字行与浅灰已修；面值 76/152rpx 登记为优惠专用 display token，其余字号回归现有字阶；CSS 票券图标待正式 Lovart WebP。

剩余未决（不阻塞视觉定稿，阻塞上线）

  • 保底权益来源：需要一个池级保底机制（如 event_pools.guaranteed_deal_id + 迁移），否则触点 1 不上。
  • 「独家」措辞：默认文案已统一为「专属优惠」；只有签署真实独家合作的门店，第 5 格才切换为「独家优惠」，需后台字段驱动而非手改文案。
  • 套餐字段与录入：set_menu 类型、套餐价/原价（分）、内容一句话需加进 venue_deals 与 VenueDealsManager.tsx；录入端用本稿卡面做实时预览，折扣值限制 0–90 整数，防止「20 = 8 折」填反。
  • 无酒精桌的套餐适配：含酒套餐不得分配给 alcohol_options 为无酒精的池，需在选场/选权益时作为准入条件。
  • 权益失效的兜底：门店临时停用或换场导致权益不可用时的替代方案与补偿口径，需商业条款文档定义（本稿不涉及）。
