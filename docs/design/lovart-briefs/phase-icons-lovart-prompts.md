## Generation Notes for Lovart

1. **Source resolution:** Generate at 240×240px. Taro will downscale to 80px or 120px as needed.
2. **Style:** Clean, modern illustration with soft shading. Not flat, not photorealistic.
3. **Background:** Solid or very subtle gradient — must remain legible when overlaid on any UI background.
4. **No text rule:** The prompt explicitly forbids text, symbols, and readable characters. If Lovart generates text-like artifacts, regenerate.
5. **Batching:** Process in groups of 3. Review each at actual 80px size before proceeding to the next batch.
