**街头盲盒 NPC｜阿浪 + Profile V1.7 (2026-07-15):** `pages/alang` is a server-recovered story subpackage. `GET /api/alang/missions/:slug` `myProgress`/archive is the stage authority; stale search/dialogue/companion/result URLs must redirect from server stage. Search never receives target coordinates and its Map shows only the user. The product search hint is 300m; JoyJoin's fixed 5m consecutive-stable geofence remains arrival authority. Strict non-production single-test exposes direct Search “simulate found” and Companion “simulate arrived” controls through existing Mock GPS; current-run points stay on `alang_mission_progress` and never fall back to demo coordinates. Coordinates are GCJ-02 `latitude/longitude`; missing `APP_MODE` fails closed. FUTURE 04 and REMOVED 09 remain forbidden. A 2026-07-15 product override replaces ACTIVE 07's archive-list data model with a private append-only personal story (`/api/personal-story*`): one server-verified non-debug Alang or fully completed Blind Box experience per chapter, MiniMax primary/DeepSeek fallback, keywords only, no invented facts or synthetic fallback. Blind Box eligibility uses the acting user's group outcome to bind the group and additionally requires the user to be matched, the non-test pool/group to be uncancelled and finished, and that event's current-user `event_feedback.completedAt` to be non-null; group outcome alone is insufficient. `personalStoryEnabled=false` closes its client entry and GET/POST/status before any story-table access; only a flag-enabled provider outage preserves GET access to old chapters while updates fail. The same override authorizes a Profile-only minimum My Image/equipment loop (`/api/equipment/*`): 12 Profile-only 512×768 transparent pixel animals on the existing warm-white/purple UI, four removable slots, explicit versioned save, venue/mission pools, fourth-draw new-item pity, universal fragments, and fragment-only shop. The approved base-character assets already include safe initial clothing. Equip/unequip/save/inventory remain server-backed state, but until formal per-item layered raster is approved and published the UI must keep the clothed base character and omit that item's visual layer entirely; never synthesize purple geometric or other code-native equipment blocks. Character-image failure may still use the character-only fallback. `profilePixelAvatarEnabled`, `equipmentRewardsEnabled`, and `personalStoryEnabled` are independent and default false; migrations/seed must precede rollout. Formal Alang art remains `awaiting-approved-art`; labelled placeholders must not be claimed as final. Canonical doc: `docs/alang-prototype/implementation-map.md`.

**街头盲盒正式版｜多数字动物 NPC (2026-07-30 current override):** The formal surface reuses the `pages/alang` subpackage but is a separate server-owned flow under `/api/alang/flash/*`; legacy `/api/alang/missions/:slug` remains compatibility/internal only. Discover renders a static entry with no location/API prefetch. The Flash page shows current online NPCs plus held tasks; all NPCs are fictional digital animals and no real NPC is on site. Shenzhen-only fixed weekdays: 阿浪 Tue/Thu/Fri, 栗子 Mon/Wed/Sat, 默默 Wed/Fri/Sun, 拾柒 Tue/Sat/Sun, 阿团 Mon/Thu/Sun. Eligible days generate 1–2 random 180–300 minute (3–5 hour) shifts within 09:00–21:00, >=90 minute same-NPC gap, balanced dayparts, approved location allow-lists, and no future schedule disclosure. Location is one-shot GCJ-02 with no IP fallback; the server reuses `TENCENT_MAP_KEY` for reverse geocoding and proceeds only for an explicit Tencent Shenzhen/district result—missing key, upstream failure, fallback, incomplete fields, or non-Shenzhen all fail closed. Except for the required HTTPS request to Tencent Maps, raw user coordinates must not persist, enter logs/audits/analytics/JoyJoin business URLs/client query keys, or be returned. The search page may receive and display the admin-reviewed public-area address text; hidden encounter coordinates, route, exact distance and distance bands never reach clients. NPC encounter arrival is server-owned at 100m and locate is rate-limited. Unlocked dialogue lasts 24h and contains <=2 structured questions, one random reviewed task, and one reroll. The reviewed runtime library is 30 tasks (6×5), no runtime LLM; users may hold <=3 and <=1 per NPC, accepted tasks last 7 days, `ready_to_deliver` persists until a distinct later encounter with that NPC, and repeats decay by `max(5%, 0.35^n)`. Destination arrival remains 50m; entry, purchase, photo, QR, rating, staff/stranger interaction, rewards, appointments and push are forbidden. Optional <=100-character private replies are excluded from profile/analytics/story/LLM/admin surfaces and cleared 30 days after delivery. Personalization and each source default off. Admin `/admin/alang` separates encounter locations, destinations, NPCs, tasks and next-day schedules; operator+ writes are audited, Tencent reverse-geocode must verify Shenzhen/district before approval, edited approved locations fall back to inactive draft, unsafe destination withdrawal retracts live tasks, and task review uses content-version CAS. `alangEnabled` remains default false until live DB inspection, additive migration, seed, human approvals, server-side Tencent Map readiness, staging, and WeChat-device gates pass. Canonical docs: `docs/alang-prototype/implementation-map.md`, `flash-formal-privacy-and-safety.md`, `flash-schema-rollout.md`.
