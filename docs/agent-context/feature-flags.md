# Feature Flags — Agent Context

> Extracted from AGENTS.md §6 (2026-07-31). Load when adding/changing/auditing a feature flag. Skill: `feature-flags-launch-config`.

**Feature Flags (DB-backed, 2026-07-15):** `apps/server/src/lib/featureFlags.ts` is the canonical resolver. DB row is source of truth; env var is fallback. 5s LRU cache (disabled in test env). Kill switches exposed in auth response `features`: `restartOnboarding`, `smartProfession`, `onboardingForceSkip`, `matchingLiveReveal`, `socialIcebreakerClientForceEnd`, `runPlanTemplatesEnabled`, `promoBannerEnabled`, `personalityShareEnabled` (gates share poster generation), `personalitySlotAnimationEnabled` (gates slot machine reveal animation), `personalityTestEchoEnabled` (gates answer-echo loading state, default `true`), `squadUnboxingDragRevealEnabled` (default `true`), `socialSquadComposedHeroEnabled` (default `false`), `profileRedesignEnabled` (Profile parent rollback, default `true`), `profilePixelAvatarEnabled` (Profile-only pixel avatar/My Image, default `false`), `equipmentRewardsEnabled` (inventory/rewards, default `false`), `personalStoryEnabled` (entire private-story surface and updates, default `false`), `socialIcebreakerCustomModeEnabled` (default `true`), `oracleCardCornerStatEnabled` (default `true`), `personaSnapshotEnabled` (default `true`), `matchingPuzzlePreludeEnabled` (default `false`), `matchingOperatorReviewEnabled` (default `true`), `poolTeaserEnabled` (gates the pre-registration flow teaser strip `PoolTeaserStrip` inside the XiaoyueLetterCard on pool-registration, env `POOL_TEASER_ENABLED`, default `false`), `flowIntroEnabled` / `flowLifecycleEnabled` (per-flow kill gates for the two once-per-user flow-animation overlays, `FLOW_INTRO_ENABLED` / `FLOW_LIFECYCLE_ENABLED`, default `true`; see `docs/agent-context/flow-animation.md`). Server-side kill switches (not exposed in auth) include `paymentsEnabled`, `registrationEnabled`, and `venueAssignmentEnabled`. Auth resolution is parallel (`Promise.all`). Admin portal `/admin/feature-flags` (super_admin only) provides toggle UI with source badges, saving state, confirmation for dangerous flags, and audit metadata. Admin mutation is logged to `admin_audit_logs` with action `FEATURE_FLAG_UPDATED`; PUT validates the key against `FLAG_ENV_MAP` and value against `z.enum(["true", "false"])`.

> **Profile V1.7 rollout note (2026-07-15):** `profileRedesignEnabled` is the server-owned parent rollback switch for `pages/profile/index.tsx`. `false` renders the compact real-data fallback and skips V1.7 gamification/equipment/personal-story requests. `profilePixelAvatarEnabled`, `equipmentRewardsEnabled`, and `personalStoryEnabled` remain independent child switches. `personalityShareEnabled` still governs personality-result sharing; it does not imply a Profile-tab share action.
