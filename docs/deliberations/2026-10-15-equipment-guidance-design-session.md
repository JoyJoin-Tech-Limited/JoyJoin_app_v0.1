# 装备视觉系统引导设计 — 三方专家会诊纪要

> 2026-10-15 · 参与者：UX 设计总监 (taro-engineer)、PM、商业变现顾问 · 主持：主 agent
> 任务：为「我的」页的装备视觉系统设计一套引导（参照 interest-selection 引导逻辑），让用户知道**这是干什么**、**怎么攒到装备**，全程守住 精致度 + 高级感。

---

## 0. 地面事实（代码校验过的前提）

- **攒装备唯一通路**：真实完成线下活动 → 服务端授予「地点装备池抽取资格」（永久保留、手动开启）→ my-image 待领取区手动开启 → 装备或碎片 + 保底推进。重复装备转 10/30 通用碎片，碎片商店 40/120，**不接现金**（PRD §52；无购买商店为永久红线）。
- **经济参数**：每池 4 普通 + 2 稀有，权重 80/20；第 4 抽保证当前池新品（仍有新品时）。
- **现状缺口**：
  - `profile_first_visit`（P6, 2026-09-11）对每人只触发一次、不看装备状态 → earning loop 启动后不再有教育。
  - 权益授予目前以 toast 收场 → 用户「从未得知」拥有抽取机会。
  - 零装备空态（profile 装备栏「0 件」/ my-image「这个部位还没有获得装备」）是无叙事的死文案。
  - my-image 页无吉祥物、无「装备从哪来」说明；确认弹窗文案有保底提示但无来源叙事。

## 2. 交叉共识（六簇收敛 — 设计立法）

1. **待领取是全系统最高意向瞬间。** 三方不约而同押注：UX 的待领灯+领取引路、PM 的接力棒、商业的图鉴回访，本质是同一旅程的三段。
2. **循环句只有一句**：「一切成长来自真实到场」。PM 的循环句、UX 的潮流同源一行字、商业的诚实文案，是同一句话的三个语气版本。
3. **手动开启是唯一仪式。** 抽取瞬间 = 峰终定律里的 peak：UX 做仪式（三拍）、PM 做认知（回响卡）、商业做转化（下一场 CTA）——三者叠加而不是三选一。
4. **保底是信任仪表盘，不是促销文案。** 刻度尺语言（数着抽、第四下必中）替代概率语言，恰是「反赌感经济」的道德卖点。
5. **零态 = 完备而非缺失。** fullStarter 已上身、行头即记忆——空态永远是路标，绝不是羞耻。
6. **反 FOMO 是三方共同红线。** 商业的否决清单（限时/过期/连签）与 PM 的疲劳守则（dismiss 记忆、24h 单 tip、>40% 断路）与 UX 的克制美学（呼吸信标而非红点轰炸）互相印证。

## 4. 统一方案 — 三幕引导（equipped guidance arc）

### 第一幕 · 看懂（我的页，零态到常态）
- **零橱叙事**：装备栏计数位换「完成第一场活动，就能赢装备」；4 枚虚线圆 90ms 错峰 settle。
- **潮流同源**：growth 卡一行「潮流值随真实活动增长 · 装备也是」（tap-through my-image）。
- **循环句三锚点**：零态卡脚注 / 抽后回响卡脚注 / my-image 空权益区「下一次机会藏在下一场活动里」。

### 第二幕 · 去领（权益时刻，三段接力）
1. **待领灯**：装备栏暖金呼吸点 + ≤7 字 chip（「可领取」兜底）——纯数据驱动、永不过度打扰。
2. **领取引路 tip**：首次权益出现时 C4 队列弹 `profile_equipment_first_entitlement`，行点击直达 my-image；`profile_first_visit` 未看时排队（同 session 单 tip 纪律）。
3. **接力棒落地**：到达 my-image → 待领取区块 600ms 呼吸高亮（RM 降级）→ 确认弹窗上方补一行「这次抽取来自「{poolName}」· 第 4 次抽取必出新品保底」（纯文案，不改弹窗语义）。同权益 cap 2 次常驻曝光 → 第 3 次起降级装备栏气泡。

### 第三幕 · 开抽（仪式、认知与闭环）
- **抽取三拍**：≤1.6s（0–240 凝视 / 240–720 引弓 / 720–840 裂帛 / 420ms 结果落卡），tap-to-skip 首日实现，RM 只看结果卡。
- **这一抽讲明白**：结果页内联回响卡（页内卡，非弹层）。
- **保底四格**：4 枚 40×12rpx 刻度，保底前一抽末格呼吸 + 「下抽必得保底」，保底后 160ms scaleX 重置。
- **碎片闭环**：重复装备卡「去商店看看能换什么」tap-through（禁「赚碎片」动词）；商店余额达标加同款金点。
- **出货峰值 CTA**（P2）：回响卡底部直挂当前可报名同类局（来自预测 shell，无场次中性收尾）。

### 后续幕（P2 / P3）
- **P2**：池接头图鉴（引导第一屏）、稀有出货限定分享卡、出货峰值 CTA。
- **P3**：现场记忆 provenance（逐件锚定活动，L）、潮流值里程碑联动扩展（L）。

## 5. 全局红线（任一违反 = 拒绝实现）

1. `profilePixelAvatarEnabled` / `equipmentRewardsEnabled` 任一关 → 所有引导静默、零 gamification 查询。
2. `GUIDANCE_TIP_IDS` **append-only**；契约测试（guidanceQueueContract / discoverAnalyticsAllowlistContract）全过。
3. 禁词零命中：匹配/社交/灵魂/撮合/AI/抽奖/概率/十连；不出现倒计时与任何 FOMO 时限。
4. 无购买路径；循环终点只有「报名下一场活动」；推不出可报名场次 → 中性收尾，绝不假库存。
5. 空态永远「已备好行头」，绝不出现「还没有装备/损失/错过」框架。
6. emoji 零准入 primary copy；新 bundled 资产必须同 PR 配 `packOptions.include` + `cdn-asset-manifest.json`；JoyJoinIcon 冷启动 emoji 闪规避沿用 GuidanceTipCard 的 localAsset 直 Image 模式。
7. 组件 SCSS 用于 profile-linked 页 → 必须 `@use` 进页 SCSS（subpackage WXSS 陷阱）+ `verify:subpackage-styles` 全过。
8. 动效一律 transform/opacity + `prefers-reduced-motion` 降级；禁 min()/max()/clamp()；8rpx 节奏；CTA 纯 #8B5CF6 无渐变。
9. 疲劳断路：`equipment_guidance_dismiss` 周率 >40% 连续两周 → 相关 tip 自动降级 14 天（admin 可恢复）。

## 6. 指标与最小可上线切片

**北极星**：权益授予 → 30 分钟内开抽转化 ≥60%（当前无基线，埋点先行）。
**商业门槛（A/B）**：抽完 → 7 日内报名转化绝对提升 +7% 才全量（池图鉴/峰值 CTA 适用）。
**副指标**：装备区点击率 ≥25%（新用户 7 日内）、抽后回响卡停留 ≥2s、dismiss 率 <15%。

**最小切片（一个 PR 线内可落，全 S/M、零新资源）**：
待领灯 → 领取引路 tip → 接力棒（my-image 高亮 + 弹窗来源行）→ 抽取三拍 → 回响卡 → 保底四格 → 碎片闭环 → 零橱叙事/潮流同源文案。

**埋点清单**：`equipment_zero_intro_seen/_tap`、`equipment_entitlement_prompt_shown/_tap`、`my_image_entitlement_view`、`equipment_draw_confirmed`、`equipment_post_draw_card_read`、`equipment_next_event_cta_tap`、`equipment_guidance_dismiss`（client union + 服务端 allowlist 同步，合同测试锁定）。

## 7. 精致度 / 高级感 craft bar（本设计的品味定义）

- **克制即信号**：可领取 = 一枚与形象呼吸同频的暖金光晕，而非红点+角标轰炸。
- **Education→Faded→Gone**：来路三步的密度哲学——新手在场，老手视若无睹，优雅退场而非突然消失。
- **成组的语言**：金色圆点在待领灯/入橱/商店三处语义统一为「这里有事可做」；一种方言胜过三种妙笔。
- **仪式有时限**：悬念严格 ≤1.6s 且可跳过——与金币雨式 gamification 划清界限。
- **一行字的教育**：潮流同源/循环句证明最高的克制是「一行字承担全部教育量」。
- **离散可数的公平感**：刻度尺而非概率百分比——机械公平本身就是高级感。
