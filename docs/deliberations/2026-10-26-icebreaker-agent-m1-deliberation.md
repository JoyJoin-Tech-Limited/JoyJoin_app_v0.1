## 0. 裁决摘要

| 议题 | 裁决 |
|---|---|
| 能不能交付「proper icebreaking agent」 | **能。**但必须比原 Phase 0+1 多交付：**真实动作 + 反馈复用 + 最小评测** |
| 能不能说「行业第一」 | **泛化说法 NO-GO。**Teams Facilitator、Soul 群聊派对 AI 主持已使宽口径不成立。只保留**窄类别 + 条件式**表述，且须独立竞品审计与法务签核 |
| 首发范围 | **收窄**，不是扩大：2 个 phase、1 个真实动作、无长期记忆、无 Director |
| 变现 | **不单独收费。**作为所有局的基础质量，以 30 天付费复购变现 |
| 最大技术风险 | **不是模型能力，是「应用内不活跃 ≠ 现实冷场」**——可能方向相反 |

## 1. 双方一致的七条结论

1. **原 Phase 0+1 不构成 Agent。**Ask + 文案 + 日志，只是「会主动弹出的聪明提词器」。
2. **必须有真实状态改变。**host 采纳后还要自己找按钮，就是增加工作，host 会关掉它。
3. **反馈必须进入下一次决策**，而不是只写进报表。
4. **长期记忆系统移出首发**，但**事实日志（episode/trace）必须首发就有**——前者是负担，后者是资产。
5. **Director 延后**。它解决「90 分钟怎么编排」，不是当前已验证的「卡住时没人发现」。
6. **评测必须前置**，不能放最后。没有 golden sessions 就没有对外宣称的资格。
7. **「一个真实有效的动作」胜过「三个为了凑定义接上的工具」**。原文 §11 的「至少 3 个状态工具」验收线作废。

## 3. M1 产品定义

**产品句（host 能复述的版本）**

> 这桌互动卡住时，悦仔会主动发现、先问我要不要帮一把；我点头后，它调整玩法，并在这局里根据效果决定下一步。

这句话包含用户可理解的五件事：**持续目标、主动观察、选择动作、真实执行、结果反馈**。缺任何一件，都退回「smarter mascot」。

**客户划分**
- **Host = 直接客户**：接收 Ask、采纳/忽略/关闭，所有社交敏感动作的最终门控。价值是**零培训、少一次判断、少一次翻菜单**，不是多一个控制台。
- **Participant = 体验受益者**：不收主动点名、不看个体参与度评分、不管理 Agent。
- **Operator = 安全与灰度负责人**：开关、聚合指标、异常处理，不代替实时主持。

**M1 范围**
- 仅 `warmup` + `micro_challenge`
- **1 个真实动作**：warmup 的「换一组话题卡」（写回 session state，全端同步，rejoin 一致，幂等）
- 运行时合法选择只有四种：**继续观察 / 发起 Ask / 执行该动作 / 降频或本场停止同类建议**
- **动态选择由有界策略完成，Policy Kernel 放行，LLM 继续只负责措辞。**Agent 的可信度来自闭环，不来自模型权限大小。
- Ask 合并进现有 slim host shell；手动 `⋯` 保留为 fallback
- **不新增** Agent 控制台、常驻聊天面板、participant 页面

**明确不做**：自动推进 phase、自动点名、自动换话题、个体活跃度排名、个人社交表现档案、跨场记忆读取、Director 自治、五进程多 Agent。

## 4. 头号风险：信号可能是反的

**这是本次 deliberation 最重要的新发现，原文完全没覆盖。**

当前信号观察的是**应用内交互**，不是现实谈话。一桌人聊得正投入时，`activeRate` 反而**下降**。

后果：Ask 会在最投入的时刻打断 host → 信任迅速归零 → host 永久关闭。

**对策（按优先级）**
1. **不活跃只能作为弱信号，不能单独触发。**主信号改为：phase 实际时长超 run plan 预算、完成率停滞、主动 pulse 自评偏低、话题推进停滞。
2. **健康安静反例必须进 golden sessions**，误报率先于采纳率优化。
3. **OAI 不只是礼貌，它就是误报过滤器。**Ask 本身是一次廉价的 host 确认——这是「先问再做」在本产品的额外工程价值。
4. 对外只说「互动信号异常」，**不宣称理解情绪**。

## 5. M1 验收标准

| # | 标准 | 门槛 |
|---|---|---|
| AC1 | 20 场 golden sessions（含健康安静反例） | 卡住场景召回 ≥90%；健康场次每 20 分钟误 Ask ≤1 次 |
| AC2 | host 零点击的端到端试局 | 95% 合格 Ask 在 30s 内出现在 host shell；participant 不受未批准介入 |
| AC3 | 门控 | 100% 介入先经 host 批准；可一键忽略/关闭；忽略后同类 Ask 冷却 ≥10 分钟 |
| AC4 | 真实动作 | 采纳后 6s 内生效或确定性 fallback；全端与 rejoin 一致；重试不重复执行 |
| AC5 | 闭环 | 每次 Ask 可追溯「展示—采纳/忽略—执行—后续效果」；连续被忽略会改变后续决策；本场可关闭 |
| AC6 | 安全与合规 | 最小统一检查上线；违禁可见词 0、AIGC 漏标 0、重大心理安全事故 0 |
| AC7 | 成本 | 典型 ≤12 次 LLM/场，硬上限 18 次/场、¥0.20/桌，超限落 curated fallback |

**Guardrail（不得变差）**：相对 host-only 对照，活动反馈「尴尬」选择率上升 ≤2pp；phase completion 下降 ≤2pp；Agent 相关投诉 <2%。样本不足时只能做停止/继续判断，不得宣称统计非劣。

**北极星**
- 产品：**host 认可的有效介入率** = 被采纳且达到预定义恢复标准 / 合格 Ask
- 商业：**参与者 30 天再次付费报名率**
- **Ask 点击率本身不作为成功结论**（会奖励更频繁的打扰）

## 6. 对外口径（双层）

**公众 / 小程序**（须过品牌文案评审 + 微信审核）
> 「主持人做决定，悦仔帮这一桌聊起来。」
> 「冷场时，悦仔会先问问主持人要不要帮忙。」

不用 AI、社交、匹配、撮合、灵魂、「首个」。AIGC 角标继续 fail-closed。

**投资者 / 媒体**
> 首选：「每次现场建议都跟踪采纳、参与变化与再次报名，用真实效果改进下一局。」
> 备选（需证据包）：「中国首个面向线下六人陌生人付费局、具备跨场记忆与介入效果评测的人类门控破冰智能体。」

**现在只能称「主持人提词与氛围建议能力」。** M1 验收全绿后可称「具备观察—征询—行动—反馈闭环的有界破冰智能体」。**「第一」永远需要独立竞品审计 + 明确地域/品类/时间 + 法务签核，不能由研发自封。**

**合规 P0**：当前微信提审姿态是无生成式 AI。真实 Agent 上线与该姿态冲突——未完成备案、协议更新与重新提审前，提审版本保持 LLM 关闭。另外「首个」类表述若无法验证，存在《广告法》第 4、28 条及反不正当竞争虚假宣传风险，「投资者口径」不能豁免公开广告责任。

## 7. 成本纪律（假设已标注，非实测）

假设：90 分钟 6 人桌；deepseek-flash 保守按输入 ¥2/M、输出 ¥8/M；单次 4,000 input + 300 output ≈ **¥0.0104/call**。

| 策略 | 成本/桌 | 占月卡六人桌 ¥98 收入 |
|---|---:|---:|
| **12 次/场（目标）** | **¥0.125** | **0.13%** |
| 30 次/场 | ¥0.312 | 0.32% |
| 每 3s tick 调一次（1,800 次） | ¥18.72 | **19.1%** |
| Director+Guardian 每 tick 各一次 | ¥37.44 | 38.2% |
| 五角色每 tick fan-out | ¥93.60 | **95.5%** |

**结论：3 秒 Observe 必须纯确定性计算；LLM 只在阈值触发、冷却结束、动作需要时调用。最大成本风险是「tick → 多角色 fan-out」，不是模型单价。**
同时：单场真实贡献毛利（场地、host、运营）尚无基线，不能用低 token 成本掩盖整场亏损。

## 8. 实验设计

**Stage A｜24 桌 / 144 席，行为证伪**
- 深圳单城，**同桌随机**（不按个人，避免同桌污染），同价、同 host 池分层
- 12 桌 OAI vs 12 桌现有体验；招募不提「第一」「AI 实验」以减少新奇效应
- 处理组 Ask 曝光 <100 次 → 结果无效，不得宣称成功
- **进入付费验证门**：Ask 采纳 ≥35%；host「下一场仍愿意使用」≥75%；投诉 <2%；成本 ≤¥0.50/桌；无安全事故
- **立即 kill/回炉**：采纳 <25%、host 明确反感 ≥25%、投诉 ≥2%、成本 >¥0.50/桌

**Stage B｜累计 58 桌 / 348 席，付费验证**
- 假设对照 30 天复购 20% → 目标 35%（+15pp），双侧 α=0.05、power 80%、ICC=0.05 → 约 29 桌/臂
- 若要检测 +10pp，需约 **124 桌 / 744 席**；**58 桌的「不显著」不能误读为无效**
- **商业成功**：30 天付费复购 ≥+10pp 且增量贡献毛利覆盖全部增量成本
- **商业 kill**：uplift <10pp 或增量毛利为负 → 停止 retention engine 宣传，冻结记忆与 Director 扩张，只保留改善现场体验的基础 OAI

## 9. 变现与护城河

**唯一主运动：Agent 含在现有票价与悦聚卡权益内，提升 30 天复购、三连/六连局包迁移、季卡续费。**

被拒绝的运动：
- **B2C Agent 加价包**：假设 +¥9.9/场 = 月卡单场 60.6% 溢价，无付费意愿证据，且制造「便宜票冷场」的负面分层
- **host/operator SaaS 先行**：host 采纳率是产品指标，不等于付费预算
- **企业团建 / venue B2B2C 先行**：采购周期与隐私审查更重，且稀释窄定位；复购证据后再评
- **把「第一」计入 LTV**：不产生 switching cost

**护城河排名**：① episodic 介入-结果纵向数据（条件式最强，但需要复购规模、授权与 outcome label）② host 网络与现场 SOP（当前最现实）③ eval harness ④ 12 原型人格数据（静态易复制，接上现场行为才升级）⑤ 悦仔品牌（识别价值，非技术壁垒）。**「First」不计入护城河。**

| 分歧 | 裁决 |

## 11. 待拍板（3 项）—— ✅ 已于 2026-10-26 全部由用户拍板锁定

1. **口径**：✅ **接受双轨口径**——公众只说主持人副驾，窄「首个」仅在功能 + 独立竞品证据 + 法务签核后用于投资者/媒体。公开泛化「行业第一」不使用。

## 12. M1 里程碑

**名称：悦仔破冰副驾 —— 观察 · 征询 · 行动 · 复盘**
**周期：约 4–6 周，10–14 人周。**

1. **证据与最小回放集｜3–5 天**：卡住 vs 健康安静判别样例、20 场 golden sessions、现有基线（`⋯` 打开频次、手动建议使用量、phase 完成率）、选定首发动作
2. **闭环垂直切片｜2–3 周**：趋势观察 + OAI + 1 个真实动作 + 冷却/关闭 + 反馈复用 + 最小统一安全检查；复用 AITrace、feature flag、timeout、curated fallback
3. **真实 host 试点｜2 周**：Stage A 对照实验，达标后才对外称「有界破冰智能体」
4. **之后按证据扩展**：动作覆盖不足 → 加第二动作/phase；run plan 不满 → 再评 Director；复访价值证实 → 再评聚合 episode 记忆；至少两个产品面复用后 → 再抽象完整 JSAF

## 13. UI/UX 设计评审带来的契约修订（2026-10-26，设计基线已落盘）

设计策略全文：[`docs/design/icebreaker-agent-m1-uiux-20261026.md`](../design/icebreaker-agent-m1-uiux-20261026.md)。
核心立场：**克制 = 高级；agent 的高级感来自时机与结果，不来自存在感。**默认界面零新增 Agent 痕迹，无观察灯/扫描线/常驻状态/「正在思考」。

以下 6 条是对 M1 工程契约的实质修订，优先级高于 §3–§5 中与之冲突的表述：

1. **可执行 Ask 只在 `warmup`。**`micro_challenge` 没有第二个真实动作，因此只保留观察与反馈复用 + 现有手动建议入口，**不得展示「采纳后仍需 host 手动完成」的假闭环 Ask**。M1 的「2 个 phase」由此精确化为：2 个 phase 观察，1 个 phase 可行动。
2. **取消 8 秒自动消失。**可执行 Ask 只在采纳 / 先不用 / 本场关闭 / 失效（phase 切换、session 结束、证据失效）时关闭。决策语义必须区分并**服务端持久化**：`ignored`（显式先不用，冷却 ≥10 分钟）、`expired`（不算忽略、不冷却）、`action_failed_dismissed`（不记作否定建议）、`closed_session`。不得复用现有 `adaptiveSuggestion` 的 8s timer 与本地 `dismissedSuggestionAt`。
3. **`warmupTopicSetRevision` 是全端唯一事实。**整组换题可能仍是 index 0，不能只监听 `currentTopicIndex`；不允许本地乐观 deck；agent 执行 pending 是 host-only 状态，不广播全桌 `generating`；旧话题保留到新 deck 原子提交后才做全端过渡。
4. **AIGC 角标按 per-item meta 判定**（`aigcEnabled AND Ask.meta.aigc.aiGenerated === true`），不得只看全局开关；curated/fallback/meta 缺失一律不显示。
5. **Participant 侧唯一可感知变化是 360ms 双段内容 crossfade**（仅 transform/opacity，外框与操作区静止）；不重播 deal/flip/sheen/typewriter，无「悦仔已换题」toast、无震动。M1 不做效果回看面板、不做参与度前后对比。
6. **设计验收进入发布门槛**：WeChat DevTools + iOS/Android 真机走查（含 4s/6s/phase 切换竞争、rejoin 不重播 haptic、禁用 CTA 平台色）、`build:weapp + verify:subpackage-styles`、reduced-motion 与低性能降级、以及 host/participant 双视角用户审计。仅凭单测不得签核视觉。
