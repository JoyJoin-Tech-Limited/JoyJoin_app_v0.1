# 商业化备忘录：对标平台新手指引与报名链路的竞争裁决

**日期：** 2026-10-20　**趋势检索时间：** 检索失败，趋势引用标注「底稿来源，非实时」

## 1. 决策建议

**做一个「首访体验预览」，但绝不照抄 转化 的聊天式模拟。** 具体动作：在 Discover 页对首访未报名用户放置一张「60 秒看懂你的一晚」入口卡（复用我们已有的真实资产——原型揭晓仪式、集结房间、多阶段破冰、桌友卡），并在活动详情页补上 转化 已做成行业基准的三件信任组件：「怎么参加」时间线、透明退款政策条、收银台双人入口。四周内上线，全部走 flag 灰度。

## 2. 核心依据

- **第一性原理拆解 转化 的新手指引**：它不是功能教学，是**付费前的体验预售**——把「花 ¥88 和 5 个陌生人喝酒」这件高不确定性的事，用 2 分钟模拟成一条可想象的情感弧线（邀请函→配桌动画→话题卡→身份解锁→3万+ 人赴约）。它解决的是**冷访客的认知成本**，不是操作成本。这个需求我们也真实存在：我们的 onboarding 用匿名性格测评做获客钩子（免费、好玩、出原型），但用户测完、登录、填完资料落到 /discover 后，「报这个局之后会发生什么」仍要靠脑补。
- **漏斗哲学互为镜像，谁也不能抄谁**：对标平台 = 先付钱锁定名额，后填问卷（付款是承诺峰值动作）；我们 = 先免费测评出原型，再在报名时付钱（测评是获客钩子 + 数据护城河）。两条链路的信任峰值位置不同：他们的信任靠新手指引 + 详情页 UGC/FAQ/客服堆出来；我们的信任靠测评专业度 + 揭晓仪式堆出来。**结论：我们不需要再买一次信任，我们需要把已有的信任资产在决策点（详情页/收银台）陈列出来。**
- **单位经济我们占优，但只在续费后**：悦聚月卡 ¥98/6 场 = **¥16.3/场**，六连局包 ¥61.7/场，vs 转化 单场 ¥88（酒局含 1 杯特调）/¥58（饭局）。对标平台 每场都收全价、无锁定；我们用首场 ¥68（WELCOME20 锚 ¥88）→ 悦聚卡续费打 LTV。结构正确，但**首战即决战**：首场体验若不在详情页就把期望值管对，¥68 换来的不是 LTV 是退款风险。（PRODUCT_REQUIREMENTS.md §1.5；WELCOME20 见 §46 / PRD:200）
- **趋势引用**：线下社交/活动市场约 1800 亿元、同比 +23.6%，"线上聊不动、线下组局香"是一线城市结构性迁移；小程序私域复购率约为公域 2.5 倍 — 来源：china-market-baseline.md §3.1/§1（底稿来源，非实时，量级待复核）。搭子经济 70% 用户追求轻量关系 — 同底稿 §3.1。
- **数据缺口（待采集）**：首访用户 discover→详情页→收银台的分层转化；详情页停留时长与「联系客服」点击率基线；首单 ¥68 用户的 30 天续费率。

## 4. 衡量指标

- **北极星**：详情页 → 收银台提交转化率（当前无基线，上线前先埋点采集 2 周）
- **护栏 1**：首单退款率不升（安心补位 Phase 0 链路已有退款管道与幂等）
- **护栏 2**：首访预览卡跳过率 ≤ 60%（高于此说明内容冗余）；客服会话量不异常飙升（说明时间线没讲清楚）
- 事件埋点走 `apps/server/src/routes/domains/analytics.ts` 白名单（参照 `flash_search_started` 先例）

## 5. 风险与回滚

- **风险 1（P1）**：首访卡变成「又一层弹窗」惹烦老用户 → 仅对「无历史报名记录」用户展示，一次性 dismiss，服务端记录。
- **风险 2（P1）**：收银台展示退款政策反而抬升取消率 → 灰度 50/50 观察 7 天取消率；文案强调「排桌完成前随时全额退」的安心感而非退款动作本身。
- **风险 3（P2）**：双人入口前置分流了 Duo 邀请裂变的 ¥50 奖励曝光 → 收银台双人选项文案挂「同行有奖励」钩子，回引邀请页。
- **回滚**：全部走 `featureFlags.ts` DB flag，默认关，admin `/admin/feature-flags` 一键回滚，无 schema 变更、无数据回滚需求。

### 二、Q-A ~ Q-E 逐条裁决

- **Q-A 范围冻结：不加项。只许上一周班则砍 FAQ**，留 4 拍流程条 + 退款叙事 + 埋点（约 4 人天）。付费犹豫两大源头是「不知道会发生什么」（流程条解）和「怕亏钱」（退款叙事解）；FAQ 是密度不是卡点；埋点不可砍——砍了度量，省下的班也不知道换来了什么。
- **Q-B 游客视野：推翻登录墙，做游客可见的局预告视图（真实场次卡片只读 + 测评钩子 CTA）。** 账：① CAC 侧——投放/分享流量落到 landing 后看不到任何具体供给，转化漏在登录墙（`discover/index.tsx:1179` 游客直接渲染 LandingPage，PM 已核实）；游客视图让落地→登录转化乘一个更大系数，同预算 CAC 直接降，对标平台 Discover 全开放已验证该形态。② 数据资产侧——匿名测评钩子本来就在墙外（landing → 匿名测评 → 揭晓 → 登录链路真实存在），墙内被保护的是写操作（报名/绑定/Duo），只读视图一行不写，资产零损失。③ 最坏情况——游客看完局不满意、未留身份流失：这本来就是不会转化的流量，损失为零。④ 形态修订 PM 的 E 方案：不在测评结果页与登录之间插屏（拉长登录路径、干预中段），而是 Discover 对游客渲染只读场次卡——已登录路径零改动。首局预告片投放位置不受此影响：游客视图管获客转化（墙外），预告片管首单转化（墙内首访），两者分工不冲突。
- **Q-C 双人同行形态：维持邀请制前置，推翻一人代付两座。** 账：① 代付两座是**一阶收益**——客单当场翻倍（首单 ¥68→¥136），但被代付人不是注册用户，获客价值为零、LTV 只有一半进我们口袋，退款/改期客服复杂度翻倍，还要改排桌原子单位规则（引擎成本）。② 邀请制是**二阶复利**——被邀请人是完整生命周期用户：自己的测评、自己的悦聚卡续费可能、自己的再邀请可能（裂变系数 k>0）。③ CAC 侧——¥50 INVITE_REWARD 排桌匹配成功才发放（migration 0098，结果付费非预付）；线下活动赛道信息流投放单个付费用户成本通常三位数，¥50 买一个朋友背书、到场率高、退款率低的已验证付费用户，是本表最便宜的合规获客。④ 邀请制「转化多一跳」用文案钩子解（收银台挂「同行有奖励」回引邀请页），不改引擎。**拿裂变换一次性 GMV 是亏本买卖。**
- **Q-D 第二层揭晓：归档，现在不立项。** 账：互选揭晓仪式感优化的是活动后链路 → 复购 → LTV；但北极星（详情页→收银台转化）连基线都没有，首单是当前瓶颈，优化 LTV 是空中楼阁。PM 的「低优先级探索」商业化侧判归档——待埋点满 2 周出基线、悦聚卡续费率有读数后再重开。
- **Q-E 供给节律：现在背书，升 P1b。** 账：① 悦聚卡本质是把品类从「买单场体验」改写为「订阅周末生活方式」——订阅心智需要节律，固定周三/周六是续费率（LTV 核心驱动）的钩子，这不是运营花边，是定价模型的配套基建。② 零代码，对标平台 已验证。③ 护栏：只在供给密度够的深圳南山/福田集群承诺，文案限定「每周三/六晚固定开局（深圳）」，供给不足集群不挂这句话——承诺跳票的反噬大于收益。④ 预告片与 FAQ 文案按此背书定稿。

### 三、对 PM 分析的挑战与补强

1. **挑战：P 级排序没把最快回款放最前。** PM 把 Duo 入口（2 人天，直接动客单+获客）与预告片（M 级 4 人天，收益间接）并列 P1，把供给节律化（零代码，订阅心智基建）压到 P2「运营」。商业化排序：**P1a Duo 入口 → P1b 供给节律背书 → P1c 预告片**。回款速度与模式基建优先于内容层。
2. **挑战：PM 的 E 方案形态错误。** 「测评结果页与登录之间加一屏」拉长登录路径、干预中段，风险高于收益。正确形态是 Discover 游客只读视图（见 Q-B）——已登录路径零改动，墙前一面墙换玻璃窗。
3. **补强：陈列信任资产时加一句「平台支付闭环，真人到场核销」。** 把已有反诈底座写进信任文案，成本一句话，抵 转化 一支真人审核团队——PM 说的「写进文案比建团队便宜一百倍」商业化侧完全同意，要求落进 FAQ 首批文案。
4. **同盟：点名支持 PM 守住不造假 UGC/社会证明。** 🔴 红线不是品牌洁癖，是牌照风险。微信分发是我们 CAC 最低的渠道，一张审核红牌对 CAC 模型的打击是灾难性的——商业化侧与 PM 在此完全同盟，「往期这一桌」只用真实 recap 金句。
5. **补强：PM 全文以首单转化为轴，未给续费率权重。** ¥68 首单是亏本买用户（WELCOME20 锚 ¥88），盈利模型押在悦聚卡续费上——供给节律（Q-E）与详情页期望值管理（流程条）本质上都是续费率工程。**首单转化 ≠ 胜利；首单体验管对期望值 → 续费才是。**
