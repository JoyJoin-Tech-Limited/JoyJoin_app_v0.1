# AI Operations Engineer Intern

**Location:** Remote / On-site
**Duration:** 4–6 weeks (with extension option)
**Team:** Product & Engineering

---

## About JoyJoin

JoyJoin is an AI-powered social discovery platform. Our backend AI systems drive matching, icebreaker game generation, venue assignment, and operational workflows in the admin portal. We are pre-launch and building the operational muscle for our beta release.

## Role Summary

You will own the operational health of JoyJoin's backend and admin systems before and during beta. You will run end-to-end operational workflows in the admin portal — create event pools, trigger AI matching, assign venues, manage users, process test refunds — and validate that the backend behaves correctly under load and at the edges. You will also be the signal processing backbone for the intern team, triaging and prioritizing bugs found by the Evaluation team.

## What You'll Do

- Admin portal E2E testing: pool creation, matching runs, venue assignment, user management, payment ops, attendance tracking
- Backend validation: verify API contracts, error responses, idempotency, rate limiting, and auth boundaries
- Data integrity checks: ensure matching results, user profiles, and payment records are consistent in the database
- Bug triage: process incoming bug reports from the Evaluation team, reproduce them, classify severity, and route to engineering
- Regression tracking: maintain a regression test checklist that runs before every release candidate
- Write structured bug reports and operational runbooks for beta launch
- Collaborate with the Evaluation and Product Ops interns on weekly bug council

## What We're Looking For

- Currently pursuing a degree in CS, IS, or equivalent practical experience
- Comfortable with API testing tools (curl, Postman, Bruno — any is fine)
- Ability to read basic SQL and verify data in the database
- Systematic thinking — you can design a test matrix that covers happy path, edge cases, and failure modes
- Detail-oriented — you notice when a 201 should be a 200, or when a rate limit returns the wrong error shape
- Bonus: experience with admin portal testing, payment flow testing, Drizzle ORM, Postgres, or GitHub Issues project management

## What You'll Gain

- Real experience operating AI infrastructure before launch
- Exposure to production Postgres, API design, and deployment workflows
- Your name in beta release credits
- Direct mentorship from founding engineers
- Strong signal for AI Operations / Infrastructure roles at AI-native companies
