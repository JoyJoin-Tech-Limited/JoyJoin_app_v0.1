## 💡 TIPS FOR LOVART GRID GENERATION

1. **Upload your base model first** — Reference it explicitly: *"Use the uploaded image as the locked model."*
2. **Generate Grid 1 first** — Core expressions are more forgiving if slight inconsistencies occur.
3. **Use Remix on Grid 1 for Grid 2** — This locks the style even tighter.
4. **If expressions drift** — Annotate the specific cell in ChatCanvas: *"Cell A2 should look more knowing, less cheerful."*
5. **If the grid has layout artifacts** — Ask Lovart for a "clean version" with no grid lines or labels, just the portraits evenly spaced.
