# Icebreaker G1 Pilot Kit — Printable Ops Pack

> 2026-11-10 · Companion to [`icebreaker-g1-pilot.md`](./icebreaker-g1-pilot.md) (authoritative protocol)
> Status: **kit only; G1 has not run.** Zero tables executed, zero participants recruited.
> Nothing in this file is measured data. Any number you see is a gate threshold or a blank field.

## 0. How to use

Print this pack once per G1 run. One copy per table for §5 and §6; one copy for the observer (§7).

| Print | Who holds it | Pages |
|---|---|---|
| Light-host card (§5) | whoever arrives first, per table | 1 |
| Run sheet (§6) with warmup/challenge cards | same card stack, face down | 1 + cards |
| Observer capture sheet (§7) | observer, per table | 1 |
| Consent script (§4) | DRI, read aloud before seating | 1 |
| Manual loop forms (§8) | DRI | one per person, 2 tables (12 forms) |

Rules for the run:

- Do not edit copy blocks mid-run. If a line fails in the room, note it and change it after.
- No participant names on the observer sheet, the CSV, or the readout. Seat codes only.
- The protocol's gates are not negotiable in the room. If a gate is at risk, record the fact.

## 1. Roles

| Role | Owns | Headcount |
|---|---|---|
| Pilot DRI | Go/no-go, timeline, readout, the only person who talks to participants about the pilot | 1 |
| Observer | Timestamps and the capture sheet. Never hosts, never prompts, never sits in the circle | 1 per table |
| Safety / on-call | Distress, harassment, medical, intoxication, venue issues. Can stop a table without asking | 1 for the whole run |
| Venue contact | Room, welcome drink, staff door, closing time, a quiet corner for anyone who needs to step out | venue staff |
| Data owner | Collects sheets the same night, de-identifies, computes gates | 1 (DRI may double) |

Minimum viable crew is **4 people** (DRI + 3 observers) with the safety role carried by the DRI. Fewer than 4 means fewer tables, not fewer observers — an unobserved table is not a G1 table.

Observers do not help. If a table freezes and no participant picks up a card, the observer still does not pick it up: write down the seconds and let the protocol fail honestly.

## 3. Recruitment copy

Rules: describe the evening, not the outcome. No promise of who you will meet, no promise of a mutual result, no invented scarcity. Mention the observer — it is both honest and required for consent.

**Existing users (one WeChat message)**

> 周三晚上在深圳有一桌 6 人的局，40 分钟，纸牌为主，没有专职主持。我们在为这个形式做一次小规模试跑，会有一位工作人员在旁边记录流程时间，不录音不录像。活动后有一天时间可以私下选想继续认识的人，双方都选才会互相看到联系方式。如果你愿意来，回我一句就行。

**New users (one WeChat message)**

> 我们在深圳办一桌 6 人的小局，周三晚上，40 分钟。桌上只有纸牌，没有专职主持，谁先到谁先带一下开场。这一场是试跑，会有一位工作人员在旁边记录流程时间，不录音不录像。活动后可以私下选择想继续认识的人，双方都选才会互相看到联系方式。想来的话回我一句，我把活动页发你。

Do not add scarcity framing, a promise about who they will meet or whether anyone will choose them, or a quality-of-crowd claim. If the table is genuinely short of seats, state the number of open seats and nothing else.

## 4. Consent and privacy

### 4.1 Read-aloud version (DRI, before anyone sits down, ~60 seconds)

> 开始前说三件事。
>
> 第一，今晚是一次试跑。旁边会有一位工作人员记录流程时间，比如什么时候开始、哪张卡被跳过、冷场多久。只记时间和张数，不记名字，不录音，不录像，不拍照。
>
> 第二，活动结束后有一天时间，你可以私下选最多 5 位想继续认识的人，也可以一个都不选。谁选了谁只有我们看得到，桌上不会显示，也不会告诉你「有人选了你」。明天晚上 21:00，只有双方都选了，才会互相看到联系方式。没有互相选择的人不会收到任何通知，也不会被告知结果。
>
> 第三，没有互选的记录会在 30 天内销毁，只保留双方都同意的那部分。
>
> 中间任何一个环节你都可以跳过，也可以直接离场，不需要解释。如果今晚有任何让你不舒服的事，找我或者找门口那位同事都可以。

### 4.2 Short written version (sent T-1)

> 这场是试跑：有一位工作人员在旁记录流程时间，不录音、不录像、不拍照，不记录姓名。
> 活动后 24 小时内可以私下选 0–5 位想继续认识的人；双方都选，次日晚 21:00 才会互相看到联系方式；不会显示谁选了你，也不发拒绝通知。
> 未互选的选择记录 30 天内销毁。
> 任何环节可跳过，可随时离场，不需要解释。
> 安全联系人：（填入姓名与电话）

### 4.3 What we never collect

No audio, no video, no photos of the table, no chat screenshots, no WeChat IDs, no selection targets in the analytics sheet, no free-text health or family detail. If a participant volunteers something sensitive, it stays out of the sheet.

## 5. First-arrival light-host card (print one page, A5)

```
──────────────  G1 轻主持卡 · 正面  ──────────────

你最早到，这一桌先交给你 3 分钟。

你只做三件事：

1. 开场
   照下面的话念一遍，然后让大家各说一句
   自己的名字和一个今天的心情。

2. 翻牌
   每次翻一张，念出来，然后等。
   谁想接就谁接，不用点名。

3. 收尾
   最后一张卡念完，说一句「今晚到这儿」，
   把牌收起来。

这三件事之外，你不需要负责任何事。
这一桌是大家的，不是你的。

──────────────  G1 轻主持卡 · 背面  ──────────────

开场就说这三句：

  我们六个都是第一次见。今晚就 40 分钟，
  靠这几张牌走，没有专职主持，我早到一点，
  先带一下。

  先一人一句：名字，加上今天到现在的心情，
  一个词就行。

  规则只有一条：不想说就跳过，跳过一次不解释，
  也没有人追问。

跳过： 「哪张不想聊，直接说『过』，翻下一张，不用理由。」
交牌： 「牌放桌上，谁都可以翻。我也可以随时把牌交出去。」
```

The opening ends when the first card is face up. That is the whole opening — no self-introduction round, no rules speech, no agenda.

Do not say: 「今晚靠你了」「你来主持」「大家听你的」. The first arrival holds three actions for three minutes, not the evening.

## 6. 40-minute paper run sheet (BREEZE 40)

Paper only. No app, no timer on screen, no generated content, no auction, no mini-script block. Minutes are from the table's own start, not the clock.

| Min | Block | What the table does |
|---|---|---|
| 0:00–0:03 | 开场 | Light-host reads §5 script. One line each: name + today's mood |
| 0:03–0:10 | 话题卡 | 4 cards, light before deep, one at a time |
| 0:10–0:20 | 挑战 | 1 challenge, 8 minutes, 2 minutes of buffer |
| 0:20–0:35 | 侦探 | 2 rounds, one turn per person per round |
| 0:35–0:40 | 收尾 | One line each + the 24h loop in one sentence |

### 6.1 话题卡 (4 cards, face down, in this order)

1. **今晚来这儿，你最期待发生什么？**
2. **最近最离谱的一次外卖经历是什么？**
3. **小时候最想当什么？现在还这么想吗？**
4. （可选，深）**最近有没有一个瞬间，让你突然心里一暖？**

Flip only as many as fit. Card 4 is optional in every table. If the table is quiet after card 1, go to card 2 — do not explain the silence, do not add a rule.

**Optional pass:** every person may pass once, no reason given, and the table moves on. Announce it once at card 1 and never again.

### 6.2 挑战 (pick one, 8 minutes)

- **找 3 个共同点** — 在座所有人一起找出 3 个共同的爱好或经历，越具体越好。（3 分钟）
- **用 3 个词形容彼此** — 每人用 3 个词形容坐在自己右边的人，不许重复。（2 分钟）

Run one. If the first finishes early, run the second; if it lands flat, say 「这个过了」 and move to 侦探. A flat challenge is data, not a rescue call.

### 6.3 侦探 (15 minutes, 2 rounds)

Say once:

> 每人写 3 句关于自己的话：2 句真的，1 句假的。写完折起来放中间，一张一张读，大家一起猜哪句是假的。
> 不写身体、家庭、工作上的敏感信息；不想写可以只写两句真的加一句很小的假话。

Per person: ~30 seconds reading + ~30 seconds guessing. Two rounds so everyone goes once per round. Do not rank who was hardest to read, do not keep a score on the table.

### 6.4 收尾 (5 minutes)

> 一人一句：今晚让你记住的一个瞬间。
> 明天晚上 9 点，我们会私发一个选择，最多选 5 位想继续认识的人，也可以不选。双方都选，才会互相看到联系方式，不会告诉你谁选了你。

Then the light host says 「今晚到这儿」 and stacks the cards. No group photo.

## 7. Observer capture sheet

One sheet per table. Seat codes, never names. Times are `mm:ss` from the table's own 0:00.

| Field | How to record |
|---|---|
| `table_id` | G1-T1 / G1-T2 / G1-T3 |
| `seat_count` | filled seats at start (record 4 and 5 separately, they are not the main set) |
| `first_arrival_minutes` | minutes before 0:00 that seat A1 sat down (negative if late) |
| `light_host_emerged` | Y / N — did the first arrival actually open the table within 3 minutes |
| `first_card_minutes` | 0:00 → first card face up |
| `skipped_cards` | count + which card numbers |
| `longest_silence_seconds` | longest gap with nobody speaking; stop counting at 120 |
| `professional_rescue` | Y / N — did staff have to take over to keep the table moving. A tablemate picking up a card is **N** |
| `safety_incidents` | count + one-line fact, no names |
| `ops_minutes` | staff minutes on this table, excluding observation |
| `would_meet_again_count` | how many of the 6 answered 「愿意再来一桌」 (0–6) |

Notes column: handoff happened (Y/N), who flipped card 2, anything that broke, verbatim quotes only if de-identified. Write the sheet during the run, not after — post-hoc timestamps are not timestamps.

## 8. Manual 24h mutual loop (2 of the 3 tables)

Paper only. This is the only place where a participant's choice exists, so it gets treated as sensitive from the first minute.

**Form (one per person)**

```
桌号：G1-T_      座位码：A_        日期：____
最多选 5 位想继续认识的人，写座位码；一个都不选也可以。
1. ____   2. ____   3. ____   4. ____   5. ____
截止：____（活动开始 +24h 之后的第一个 21:00，北京时间）
```

**Collection**

1. Within 3 hours of the event, DM each person privately. Never a group chat, never a public form.
2. Do not send reminders that imply popularity. One reminder only, and it says only 「今晚 9 点前还能改」.
3. Deadline = the next 21:00 at or after `eventStart + 24h`. If +24h lands exactly on 21:00, that is the deadline.
4. Two people hold the forms: DRI and data owner. Nobody else reads them.

**Reveal, 21:00**

- Compare forms seat-code to seat-code. A mutual pair exists only if both wrote each other.
- DM each mutual pair separately, both sides, same minute. Never CC, never a group.
- Copy: 「你们互相选择了。这是对方的微信：____」 plus one line: 「要不要加，你们自己定。」
- **Zero-mutual copy:** 「本轮先到这里。下一桌，认识新的人。」 Nothing else. No count, no explanation, no apology, no hint that anyone was close.
- If asked directly 「有人选我吗」: 「这个我们不说。规则是双方都选才会互相看到。」 Say it once, do not soften it.
- Same evening, after the reveal, one question per person: 「如果下一桌还有这个环节，你愿意再用吗？」 Ask quiet participants and anyone with zero mutuals **first**, and record the answer without arguing with it.

**Record (no names)**

| Field | Value |
|---|---|
| selections per person | count only (0–5) |
| mutual pairs | count + seat-code pairs |
| mutual → actual contact exchange | count, checked at +2h |
| zero-mutual participants | count |
| would use the loop again | count of yes |

## 9. Safety incident script

**Stop the table immediately if:** harassment or unwanted touching, someone is crying and cannot continue, a medical issue, someone is drunk to the point of not being safe, a privacy breach (a form or a selection is seen by another participant), or any participant asks to stop.

**Say (verbatim, calm, no debate):**

> 我们先停一下。
> （to the table）这一轮到这里，大家先喝口水，不用讨论刚才的事。
> （to the person affected, away from the table）你先跟我说一下发生了什么，不需要重复细节。你想走、想换位置、想现在结束，都可以。

**Do**

- Separate first, ask second. Never ask the table to vote on whether something was a problem.
- One staff member stays with the affected person; another handles the room.
- Offer the quiet corner and the exit. Call the venue contact for a taxi if needed.
- Write the facts within 24 hours: time, seat codes, what was said or done, what was done about it. No names, nothing the person said in confidence.
- Tell the DRI the same night, even if it resolved itself.

**Do not**

- Do not ask the affected person to move seats as the only action.
- Do not ask them to repeat the story to a second staff member.
- Do not promise confidentiality you cannot keep; say what will be written down.
- Do not continue the table "because it's almost over".

**Escalate**

| Level | Trigger | Action |
|---|---|---|
| Table stop | anything above | Stop that table. Record. DRI decides whether the other tables continue |
| Run stop | privacy breach, harassment, or any physical safety issue | Stop G1 entirely. Notify every participant the same night. No G2 decision from this run |
| Emergency | medical, violence, threat | Call 120 / 110 first, then the venue contact, then the DRI. Do not handle it alone |

A stopped table is a valid G1 result. Hiding a stop to protect the gate is the one failure that cannot be recovered.

## 11. G1 gate checklist

Score per table. All must hold.

| Gate | T1 | T2 | T3 |
|---|---|---|---|
| 40-minute run completed | | | |
| ≤1 skipped card | | | |
| No silence >90s | | | |
| Professional rescue = 0 | | | |
| Light-host card opened | | | |
| Natural opening without staff prompt | | | |
| Ops ≤20 min | | | |
| ≥4/6 would attend again | | | |

Loop gates: no privacy incident; zero-mutual participants do not report feeling punished; at least one mutual pair in each loop table.

Pre-registered reading: both light-host card opened and natural opening must hold in **3/3 tables**. Do not reinterpret this after seeing results.

Any safety or privacy incident stops G1. A "mostly passed" table is a fail.

## 12. Non-conclusions and do-not-scale box

```
DO NOT SCALE YET
□ 3 tables / 18 seats is a feasibility rehearsal. It cannot detect a small effect.
□ G1 cannot say whether a professional host is worth paying for. That is G2.
□ G1 cannot say whether the 24h loop improves retention. That needs real cohorts.
□ G1 cannot price anything. No number from this run justifies a price change.
□ No city expansion, no second venue tier, no weekday/weekend mix.
□ No production flag flip, no marketing claim, no external comparison.
□ Do not publish "pass rate", "mutual rate", or "would return" as a product metric.
□ If a gate fails, the answer is repeat G1 — not "close enough".
```
