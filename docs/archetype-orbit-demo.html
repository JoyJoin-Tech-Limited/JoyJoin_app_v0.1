🎭 ArchetypeOrbit Component

JoyJoin Matching & Reveal Flow UI

Live Demo

Key Features

  • Logo wake-up animation with smooth scale and fade
  • Staggered fly-in for 4-6 archetype PNGs (0.1s delays)
  • Three configurable sizes: small, medium, large
  • Graceful fallback for unknown archetype names
  • Maps 12 JoyJoin archetypes to transparent PNG assets
  • Optimized for 60fps with CSS transforms
