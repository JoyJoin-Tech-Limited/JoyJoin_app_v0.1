# Lovart Batch 2 — Celebration Frames (5 Assets)

> **Brief set for:** auction, personality_dice, undercover_word, group_mirror, quip_battle  
> **Purpose:** Emotional payoff moments — the "screenshot and share" frames that appear at game climaxes  
> **Style lock:** JoyJoin low-poly geometric faceted illustration (插画风统一)  
> **Color consistency:** All palettes reference Batch 1 card backgrounds  
> **Request approach:** Generate as a transparent-frame set in one ChatCanvas session

---

## Shared Style Parameters (Inject into every brief)

**Construction:** 2D digital illustration with low-poly / geometric faceted aesthetic  
**Textures:** Painterly, soft brushed feel within each polygonal facet — NOT flat vector or 3D render  
**Outlines:** Minimal or none — facet edges define form  
**Gradients:** Soft color variation within individual facets  
**Transparency:** Center 60% must be fully transparent (alpha channel) for code-overlaid text, player names, and UI elements  
**Frame treatment:** Decorative illustration concentrated in outer 40% (edges and corners) — like a ceremonial border or overlay frame  
**Characters:** Geometric polygonal bodies, large expressive glossy eyes, simplified features, warm expressions  
**Color treatment:** Natural warm palette matched to Batch 1 background; brand purple #8B5CF6 for key elements only  
**Anti-generic rule:** Must feature JoyJoin archetype mascots. Must feel like a moment worth screenshotting.

**Export spec for all 5:**
- Dimensions: 750×750px (square, full-screen overlay)
- Format: PNG with transparent center
- Transparent zone: center 450×450px minimum (60% of width/height)
- Decorative frame only in outer edges — no text, no UI
- File naming: `lovart-celebration-{phase}-{moment}-20260427-v1.png`

## Set Cohesion Checklist

Before approving all 5 as a batch, verify:
- [ ] All 5 share the same low-poly geometric faceted construction style
- [ ] All 5 have consistent painterly texture quality and grain level
- [ ] Center 450×450px of each is genuinely transparent (check alpha channel)
- [ ] Frame decorative density is consistent — no single frame feels significantly heavier or lighter
- [ ] All 10 mascots (2 per frame) have consistent eye size, body proportions, and feature simplification with each other AND with Batch 1 backgrounds
- [ ] Color palettes harmonize with their Batch 1 background counterparts
- [ ] Each frame tells a clear social story (presenter + reactor, detective + clue-weaver, winner + audience, etc.)
- [ ] Each frame passes the anti-generic test: could this exact illustration appear in a generic app? If yes → reject.
